# Mind – back-end (NestJS)

API REST do Mind. Veja o [README principal](../README.md) para instalação e execução.

| Comando | O que faz |
|---|---|
| `npm run start:dev` | sobe a API em modo watch (porta 3000) |
| `npm run lint` | análise estática (oxlint) |
| `npm test` | testes unitários (Vitest) |
| `npm run test:e2e` | testes ponta a ponta (Vitest + Supertest) |
| `npm run test:cov` | testes unitários com relatório de cobertura |
